Luxicon for Mac 1.0 (19)

- Cohere Transcribe (optional): a new "best quality" transcription engine in Settings → Transcription. It downloads a 1.6 GB model the first time you use it and needs about 4 GB of memory while transcribing.
- Fixed: a crash when you muted your microphone with AirPods or a headset while recording.
- Automatic updates: Luxicon now checks GitHub for new versions after asking you first, and shows what's new before installing. Nothing about you or your meetings is sent. Luxicon → Check for Updates… works any time.

If you have build 18, download this version by hand once. Future updates will arrive in the app.
